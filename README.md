# Task 5: Exploratory Data Analysis (EDA) on Titanic Dataset

## Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on the Titanic Dataset using Python. The objective is to understand the dataset, identify patterns, analyze relationships between variables, and discover factors that influenced passenger survival.

Exploratory Data Analysis is an essential step in data analysis as it helps uncover meaningful insights before building predictive models.

## Objective

* Understand the structure of the Titanic dataset.
* Analyze missing values and data quality.
* Explore passenger demographics and survival trends.
* Identify relationships between features using visualizations.
* Generate meaningful insights from the data.

## Key Findings

* More passengers died than survived in the Titanic disaster.
* Female passengers had a significantly higher survival rate than male passengers.
* First-class passengers had better survival chances than lower classes.
* Most passengers were between 20 and 40 years old.
* Fare values contained several outliers, indicating large variations in ticket prices.
* Passenger class and fare showed noticeable relationships with survival.
* Missing values were mainly present in the Age and Cabin columns.
* Survival rates varied across age groups and embarkation ports.
* Gender, passenger class, and fare were the most influential factors affecting survival.

## Project Outcome

The analysis successfully identified important survival patterns and relationships within the Titanic dataset. The project demonstrates the practical application of Exploratory Data Analysis techniques to extract insights and support data-driven decision-making.
